# Learning to Cut for MILP

Research sandbox for **machine-learning-guided cutting-plane selection** in mixed-integer linear programming.

The project uses transparent 0–1 knapsack instances so that candidate cuts, validity, LP-bound improvement, and learned selection can all be inspected directly. It is inspired by the learning-to-select-cuts literature, but it is not a reproduction of SCIP/Gurobi cut-management internals.

The core loop is:

```text
MILP instance
  -> LP relaxation
  -> valid cover-cut candidates
  -> candidate features
  -> cut selector (efficacy / random / learned / oracle)
  -> add selected cuts
  -> resolve LP
```

Expert labels are generated by **one-step LP-bound improvement**: each candidate cut is temporarily added to the current LP relaxation and the resulting reduction in the maximization upper bound is measured. The learned model is trained to rank/select cuts with high expert improvement.

## Scope

- valid knapsack cover inequalities;
- LP relaxation solved with SciPy/HiGHS;
- cut features: violation, efficacy, support, normalized cover weight, objective alignment;
- classical efficacy and random baselines;
- oracle one-step bound-improvement selector;
- PyTorch learned scorer;
- repeated-seed benchmark of bound closure and LP solves.

This repository intentionally isolates **cut selection**. It does not claim to reproduce production cut pools, separator scheduling, aging, local/global validity handling, or the full cut-management stack of modern MIP solvers.

## Run

```bash
pip install -e ".[dev]"
python scripts/train.py
python scripts/benchmark.py --checkpoint checkpoints/cut_scorer.pt
pytest -q
```

## Research grounding

Relevant lines of work include Huang et al., *Learning to Select Cuts for Efficient Mixed-Integer Programming* (Pattern Recognition, 2022), subsequent supervised cut-selection work, and recent learned cut-generation/aggregation research such as Learn2Aggregate (AAAI 2025).
